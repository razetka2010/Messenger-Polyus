# Полюс

**Полюс** — адаптивный браузерный мессенджер для личного общения и сообществ. Он поддерживает личные переписки, закрытые группы и открытые каналы, работает на компьютерах и телефонах и доступен на русском и английском языках.

## Возможности

- Регистрация и вход с уникальным `@username`, профилем и аватаром.
- Личные чаты, закрытые группы и публичные каналы с ролями владельца и администратора.
- Realtime-доставка сообщений, индикаторы непрочитанного и push-уведомления браузера.
- Редактирование и удаление сообщений, история с постраничной загрузкой и поиск по чату.
- Вложения, изображения, миниатюры, просмотр медиа и список файлов.
- Информация о чате: участники, медиа, файлы и ссылки.
- Просмотр профиля, блокировка пользователей и отключение уведомлений для чата.
- Установка на главный экран как PWA.

## Быстрый запуск

Нужен [Node.js](https://nodejs.org/) версии 20 или новее.

```bash
git clone <URL-репозитория>
cd <папка-проекта>
npm ci
npm start
```

Откройте [http://localhost:3000](http://localhost:3000).

По умолчанию сервер слушает все сетевые интерфейсы. При запуске он выводит LAN-адреса, по которым можно открыть приложение с другого устройства в той же сети. Для этого также может потребоваться разрешить входящие подключения к порту в брандмауэре.

### Настройки сервера

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `PORT` | `3000` | Порт HTTP-сервера |
| `HOST` | `0.0.0.0` | Адрес, на котором слушает сервер |
| `POLUS_COOKIE_SECURE` | `false` | Установите `true`, если HTTPS завершается на reverse proxy перед Node.js |
| `POLUS_PUSH_CONTACT` | `mailto:admin@example.com` | Контакт оператора для VAPID Web Push |
| `POLUS_DAILY_UPLOAD_LIMIT` | `1073741824` | Суточная квота загрузок на пользователя, в байтах |

Пример для PowerShell:

```powershell
$env:PORT = "3001"
$env:POLUS_DAILY_UPLOAD_LIMIT = "1073741824"
npm start
```

Пример для Linux/macOS:

```bash
PORT=3001 POLUS_DAILY_UPLOAD_LIMIT=1073741824 npm start
```

## Push-уведомления

Push требует HTTPS (для локальной разработки подходит `localhost`), разрешения пользователя и поддержки Push API браузером. Для production задайте корректный контакт оператора и используйте HTTPS:

```powershell
$env:POLUS_PUSH_CONTACT = "mailto:admin@example.com"
$env:POLUS_COOKIE_SECURE = "true"
npm start
```

На iPhone и iPad push доступен для установленного на экран «Домой» веб-приложения при iOS/iPadOS 16.4 или новее. VAPID-ключи создаются автоматически и сохраняются в данных сервера. Не удаляйте их при обновлении: после смены ключей пользователям потребуется подписаться на push заново.

## Хранение данных и ограничения

- JSON-база и загруженные файлы находятся в `data/`. Записи базы сериализуются и выполняются через временный файл с атомарным переименованием; предыдущая версия сохраняется в `data/polus-store.json.bak`.
- Вложения размером до 100 МБ загружаются потоково. Одно сообщение может содержать до 10 вложений. Суточная квота по умолчанию — 1 ГБ на пользователя.
- Пароли хранятся как хеши с солью. Сессии используют `HttpOnly` cookie со сроком действия 30 дней.
- В группе может быть до 200 участников. Текст сообщения ограничен 4000 символами, отправка — 20 сообщениями в минуту на пользователя.
- Проект не задаёт гарантированное число одновременных пользователей. Это небольшое приложение с одним Node.js-процессом и JSON-хранилищем, а не масштабируемая кластерная платформа. Допустимая нагрузка зависит от сервера, размера базы и сценария использования; для определения лимитов нужно нагрузочное тестирование.

## Безопасность и публикация

- Не публикуйте содержимое `data/`: там могут находиться база, резервная копия, сессии, push-ключи и загруженные файлы. Каталог исключён из Git через `.gitignore`, но перед публикацией всё равно проверьте `git status` и состав коммита.
- Для общедоступного развёртывания используйте HTTPS и настройте reverse proxy, обновления и резервное копирование каталога `data/`.
- Push-уведомления и резервные копии могут содержать данные, требующие защиты. Ограничьте доступ к серверу и его диску.
- Сквозного шифрования нет: оператор сервера технически может читать сохранённые сообщения.
- Страница `/privacy` — шаблон. Перед публичным запуском заполните сведения об операторе, контактные данные и условия обработки данных, подходящие для вашего сервиса и юрисдикции.
