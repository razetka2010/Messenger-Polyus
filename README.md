# Полюс

**Полюс** — адаптивный браузерный мессенджер для личного общения и сообществ. Он поддерживает личные переписки, закрытые группы и открытые каналы, работает на компьютерах и телефонах и доступен на русском и английском языках.

## Возможности

- Регистрация и вход с уникальным `@username`, профилем и аватаром.
- Личные чаты, закрытые группы и публичные каналы с ролями владельца и администратора.
- «Избранное» — личный чат для заметок и сохранения сообщений с вложениями.
- Реакции на сообщения, ответы с переходом к исходному сообщению и пересылка в существующие чаты или пользователям через поиск.
- Realtime-доставка сообщений, индикаторы непрочитанного и push-уведомления браузера.
- Редактирование и удаление сообщений, история с постраничной загрузкой и поиск по чату.
- Вложения, изображения, миниатюры, просмотр медиа и список файлов.
- Голосовые сообщения с записью, анимированной индикацией и встроенным воспроизведением.
- Информация о чате: участники, медиа, файлы и ссылки.
- Просмотр профиля, блокировка пользователей и отключение уведомлений для чата.
- Отдельная страница профиля `/profile` с редактированием данных и настройками приложения.
- Пять тем оформления: светлая, тёмная, северное сияние, лавандовая и песочная.
- Выбор русского/английского языка и настройка звука новых сообщений.
- Установка на главный экран как PWA.

При открытии чата поле сообщения получает фокус автоматически. Откройте страницу профиля из меню боковой панели или перейдите по адресу `/profile`, чтобы изменить данные аккаунта, язык, тему и звук новых сообщений. Настройки интерфейса хранятся в браузере на текущем устройстве.

При переподключении SSE сервер воспроизводит до 100 последних событий на пользователя; если пропуск слишком велик или сервер перезапускался, клиент повторно загружает состояние чатов и историю открытого диалога.

## Избранное

У каждого пользователя есть личный чат «Избранное» (Saved Messages). Он создаётся автоматически при регистрации, а при обновлении существующего хранилища добавляется для пользователей, у которых его ещё нет. Название зависит от языка интерфейса.

В «Избранное» можно отправлять заметки и сохранять сообщения из других чатов через меню сообщения. Сохранённая копия содержит текст, вложения и сведения об исходном чате и авторе. Файлы вложений не копируются на диск: они остаются доступными, пока на них ссылается хотя бы одно сообщение, даже если исходное сообщение удалено. Пересылка поддерживается в «Избранное», группы, каналы с правом публикации, личные чаты из списка и новым пользователям через поиск.

«Избранное» видно только его владельцу. Для него не считаются непрочитанные сообщения и не отправляются push-уведомления; realtime-события доставляются на все подключённые устройства владельца. Отправка сообщений, вложения, поиск, история, реакции, ответы, пересылка и редактирование/удаление работают как в обычном чате.

## Быстрый запуск

Нужен [Node.js](https://nodejs.org/) версии 20.19 или новее.

```bash
git clone <URL-репозитория>
cd <папка-проекта>
npm ci
npm start
```

Команда `npm start` собирает клиент и запускает приложение. Откройте [http://localhost:3000](http://localhost:3000).

### Разработка интерфейса

Клиент собирается Vite и запускается на React. Для режима разработки запустите API-сервер и Vite в двух терминалах:

```bash
npm ci
npm run dev
```

Откройте адрес Vite, который будет показан в терминале (по умолчанию `http://localhost:5173`). API-запросы проксируются на `http://localhost:3000`; другой адрес можно задать переменной `POLUS_API_TARGET`. Весь пользовательский интерфейс, включая вход, список чатов, поиск, формы, профиль и диалоговые окна, рендерится React. Поиск людей, создание личных диалогов, создание каналов и групп, сохранение настроек аккаунта, авторизация, загрузка истории и отметка прочтения, отправка, редактирование и удаление сообщений, а также загрузка вложений выполняются React через общий клиент `client/src/apiClient.mjs` и помощники `client/src/attachmentUploads.mjs`; кадрирование аватара вынесено в `client/src/avatar.mjs`. React также управляет SSE-подключением и presence-heartbeat; контроллер применяет полученные realtime-события и результаты API-операций к состоянию чатов через событийный адаптер. Контроллер подключается и отключается вместе с React-shell, включая очистку подписок и таймеров. Старые публичные страницы и `public/app.js` удалены; перенос логики контроллера в React продолжается.

При разработке через Radmin VPN откройте адрес компьютера, на котором запущено приложение. Для `npm run dev` используйте показанный Vite-адрес с портом `5173`, а для собранного приложения (`npm start`) — адрес с портом `3000`. В режиме Vite API-сервер `npm run server` должен работать отдельно. Запись голосовых сообщений требует безопасного контекста: `localhost` или HTTPS. Обычный HTTP-адрес компьютера в локальной сети (например, `http://192.168.x.x:5173`) браузеры блокируют; для записи с телефона настройте HTTPS. Если клиент сообщает об ошибке, откройте DevTools → Console и выполните `window.polusDiagnostics.getLogs()`; история содержит последние 200 событий этой вкладки. Подробные события набора текста с длиной сообщения видны в Console и не сохраняются в историю. Для очистки истории выполните `window.polusDiagnostics.clear()`. Содержание сообщений, пароли и имена вложений не записываются.

По умолчанию сервер слушает все сетевые интерфейсы. При запуске он выводит LAN-адреса, по которым можно открыть приложение с другого устройства в той же сети. Для этого также может потребоваться разрешить входящие подключения к порту в брандмауэре.

### Настройки сервера

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `PORT` | `3000` | Порт HTTP-сервера |
| `HOST` | `0.0.0.0` | Адрес, на котором слушает сервер |
| `POLUS_COOKIE_SECURE` | `false` | Установите `true`, если HTTPS завершается на reverse proxy перед Node.js |
| `POLUS_TRUSTED_PROXIES` | пусто | Список доверенных IP reverse proxy через запятую; только от них принимается `X-Forwarded-For` |
| `POLUS_PUSH_CONTACT` | `mailto:admin@example.com` | Контакт оператора для VAPID Web Push |
| `POLUS_DAILY_UPLOAD_LIMIT` | `1073741824` | Суточная квота загрузок на пользователя, в байтах |

Без `POLUS_TRUSTED_PROXIES` сервер игнорирует `X-Forwarded-For` и использует адрес TCP-подключения. Указывайте только точные адреса прокси, которые контролируете; для нескольких прокси перечислите их через запятую. При HTTPS HSTS включается автоматически, а при TLS-терминации на прокси задайте `POLUS_COOKIE_SECURE=true`.

Пример для PowerShell:

```powershell
$env:PORT = "3001"
$env:POLUS_DAILY_UPLOAD_LIMIT = "1073741824"
npm start
```

Пример для Linux/macOS:

```bash
PORT=3001 POLUS_DAILY_UPLOAD_LIMIT=1073741824 npm start
```

## Push-уведомления

Push требует HTTPS (для локальной разработки подходит `localhost`), разрешения пользователя и поддержки Push API браузером. Для production задайте корректный контакт оператора и используйте HTTPS:

```powershell
$env:POLUS_PUSH_CONTACT = "mailto:admin@example.com"
$env:POLUS_COOKIE_SECURE = "true"
npm start
```

На iPhone и iPad push доступен для установленного на экран «Домой» веб-приложения при iOS/iPadOS 16.4 или новее. VAPID-ключи создаются автоматически и сохраняются в данных сервера. Не удаляйте их при обновлении: после смены ключей пользователям потребуется подписаться на push заново.
Поддерживаются push endpoint-ы Google, Mozilla, Apple и Microsoft Edge.

## Хранение данных и ограничения

- Состояние приложения хранится в таблицах SQLite `users`, `sessions`, `chats`, `members`, `messages`, `attachments`, `links`, `push_subscriptions` и `upload_usage`; настройки приложения хранятся отдельно. При первом запуске импортируются данные из `data/polus-store.json` или старой таблицы `polus_store`, если они есть. Исходный JSON-файл сохраняется. Последующие сохранения записывают только изменившиеся строки; число непрочитанных сообщений и последнее сообщение чата выбираются SQL-запросами.
- Вложения размером до 100 МБ загружаются потоково. Одно сообщение может содержать до 10 вложений. Суточная квота по умолчанию — 1 ГБ на пользователя.
- Незавершённые загрузки хранятся не более 24 часов; просроченные файлы и сессии очищаются при запуске и затем каждый час.
- Пароли хранятся как хеши с солью. Сессии используют `HttpOnly` cookie со сроком действия 30 дней; смена пароля завершает все остальные сессии.
- Регистрация ограничена пятью попытками в час с одного IP-адреса. При использовании reverse proxy настройте `POLUS_TRUSTED_PROXIES`, чтобы лимиты применялись по адресу клиента, а не прокси.
- В группе может быть до 200 участников. Текст сообщения ограничен 4000 символами, отправка — 20 сообщениями в минуту на пользователя.
- Проект не задаёт гарантированное число одновременных пользователей. Это небольшое приложение с одним Node.js-процессом и SQLite-хранилищем, а не масштабируемая кластерная платформа. Допустимая нагрузка зависит от сервера, размера базы и сценария использования; для определения лимитов нужно нагрузочное тестирование.

## Безопасность и публикация

- Не публикуйте содержимое `data/`: там могут находиться база, резервная копия, сессии, push-ключи и загруженные файлы. Каталог исключён из Git через `.gitignore`, но перед публикацией всё равно проверьте `git status` и состав коммита.
- Для общедоступного развёртывания используйте HTTPS и настройте reverse proxy, обновления и резервное копирование каталога `data/`.
- Настройте `POLUS_TRUSTED_PROXIES` только если приложение доступно через известный reverse proxy; никогда не доверяйте прокси-заголовкам от произвольных клиентов.
- Push-уведомления и резервные копии могут содержать данные, требующие защиты. Ограничьте доступ к серверу и его диску.
- Сквозного шифрования нет: оператор сервера технически может читать сохранённые сообщения.
- Страница `/privacy` — шаблон. Перед публичным запуском заполните сведения об операторе, контактные данные и условия обработки данных, подходящие для вашего сервиса и юрисдикции.
